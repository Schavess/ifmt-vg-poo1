# POO I (3º INF): código de referência

Consulta da turma de Programação Orientada a Objetos I, no IFMT Campus Várzea Grande. Java, do básico à prévia de herança.

## O que tem aqui

| Pasta | Para que serve |
|---|---|
| `base_conhecimento` | Exemplos comentados. Cada arquivo mostra um conceito e roda no terminal. |
| `atividades/2026-10-27_Aula01_Biblioteca` | Prática de 27/10. No NetBeans, File > Open Project nesta pasta e complete os `TODO`. |

## Ambiente

JDK 21 e Apache NetBeans.

## Como abrir

1. Baixe ou clone este repositório.
2. No NetBeans: File > Open Project e escolha a pasta baixada.
3. A prática da biblioteca é outro projeto: abra a pasta `atividades/2026-10-27_Aula01_Biblioteca`.
4. Abra o exemplo e use Run > Run File (Shift+F6).

Há vários `main`. O botão de executar o projeto inteiro não escolhe o arquivo.

A ordem de leitura e os comandos de terminal estão em `base_conhecimento/LEIAME.md`.
